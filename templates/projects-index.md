# Project index

Instance file. Copy to `projects/INDEX.md`. It lists the projects this seat
reviews; `projects/README.md` explains how project context is kept. Start a
record from [the project template](project.md) only when a project receives
substantive or repeated review. After copying, that link becomes
`../templates/project.md`.

| Project | Local root | Knowledge so far |
| --- | --- | --- |
| <project> | `<path>` | <link to `<project>.md` once it exists; what was reviewed and its limits> |

Listing a project is context for future assignments, not a request to audit it.
Do not infer a project's purpose from its name, or repository cleanliness from
an identity check.
